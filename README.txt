SHIVANSH TRADING WEBSITE
========================

Files:
- index.html: complete responsive website
- assets/: uploaded logo, banner and product photos

PREVIEW:
Open index.html in a browser.

PUBLISH FREE WITH GITHUB PAGES:
1. Sign in at https://github.com/
2. Create a new public repository named shivansh-trading-website.
3. Upload index.html and the entire assets folder (keep the folder/file names unchanged).
4. Open repository Settings -> Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. Wait for the published URL to appear in Settings -> Pages.

IMPORTANT:
- WhatsApp enquiry form opens WhatsApp and does not store submissions.
- Confirm all business details, phone numbers and GSTIN before publishing.
- Product availability and specifications should be confirmed with the business.
- A custom domain is optional and can be connected later.
